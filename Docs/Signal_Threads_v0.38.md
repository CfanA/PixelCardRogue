# 《云海邮差》v0.38 连续路线事件

## 设计目标

原有事件提供即时的安全或冒险收益，但离开页面后不会再次影响航线。v0.38 将三个既有事件节点连接成一条可选的“信标纪事”，让玩家在前半程留下援助承诺或残骸债务，并在后续节点看到角色、信号和后果再次出现。

事件链不要求每局完整经历。玩家可以绕开事件，也可能只看到起因、回声或终章的一部分；这让路线选择同时决定战斗资源和本局故事。

## 三段结构

| 阶段 | 航点 | 作用 |
| --- | --- | --- |
| 起因 | 失联求救信标（节点2） | 协作选择建立“援助承诺”，机会选择建立“残骸债务” |
| 回声 | 风暴残骸带（节点7） | 识别此前状态；可以守约、背弃、赎回或继续加深债务；若此前没有线索，也可从这里开始 |
| 终章 | 静电观测站（节点12） | 根据承诺或债务显示完全不同的事件标题、描述、选择与结局 |

## 状态分支

| 当前状态 | 协作选择 | 机会选择 |
| --- | --- | --- |
| 尚无线索 | 建立援助承诺 | 背上残骸债务 |
| 援助承诺 | 确认护航盟约 | 背弃承诺并转为残骸债务 |
| 残骸债务 | 归还识别码并获得赎回机会 | 债务升级 |
| 承诺终章 | 建立互助航线 | 出售救援坐标 |
| 债务终章 | 结清残骸债务 | 烧毁追债应答器 |

## 终章结果

- 兑现护航承诺：强化合同核心牌、修复机体并恢复货物完整度。
- 出售救援航标：获得邮票，但承受机体与货物损失，援助网络终止。
- 归还残骸收益：交出最多30枚邮票，修复机体并恢复货物完整度。
- 烧毁追债应答器：获得邮票并结束追踪，但承受更高机体与货物损失。

以上收益与损失均为机制验证值，本轮不进行专项数值平衡。

## 玩家反馈

- 事件页新增 `SIGNAL THREAD` 章节标记和持续状态条。
- 回声与终章会根据历史选择更换标题、描述、按钮和结果文本，不仅在结算数字上产生差异。
- 路线页持续显示当前纪事状态，相关事件航点在被侦测后使用动态名称与描述。
- 最终送达页记录本局信标纪事结局，使路线故事进入单局总结。
- 新增事件链文本均提供简体中文与英文版本。

## 存档与验证

- 单局存档升级到 v4，保存信标纪事状态。
- v1、v2、v3 存档自动迁移为“尚无线索”，不猜测旧事件的历史选择。
- 自动验证覆盖承诺强化、承诺背弃、债务升级、债务赎回、四种终章及所有旧版本迁移。
