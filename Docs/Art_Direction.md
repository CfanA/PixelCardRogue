# 《云海邮差》视觉与反馈规范 v0.3

## 视觉关键词

明亮邮政、玩具飞机、复古街机、温暖末世、清晰战术信息。

## 核心色板

| 用途 | 色彩倾向 | 设计含义 |
|---|---|---|
| 天空 | 青蓝、薄荷绿 | 安全、轻盈、旅行感 |
| 玩家与纸张 | 奶油黄 | 邮件、旧纸张、温暖感 |
| 玩家识别色 | 邮政红 | 操作焦点、主要按钮、危险 |
| 机动与冷却 | 青色 | 速度、气流、降温 |
| 防御 | 金色 | 稳定、保护、货物安全 |
| 技术牌 | 紫色 | 引擎改装、非常规能力 |

## 像素栅格规则

- 飞机主体尽量由 4、8、12 像素的倍数组成，避免伪像素曲线。
- 重要单位必须具有深色轮廓，在浅色云层和航道底色上保持辨识度。
- 特效优先使用矩形、短线和色块残影，不使用平滑粒子。
- 动画采用短促节奏：攻击反馈约 0.34 秒，受击警示约 0.35 秒。
- 敌人持续进行 3—4 像素上下浮动，玩家螺旋桨使用两帧切换。

## 战斗反馈映射

| 行动 | 视觉反馈 | 声音反馈 |
|---|---|---|
| 点射 / 过载瞄准 | 同航道黄色曳光弹 | 低频方波感射击声 |
| 弹幕齐射 | 三航道错时弹道 | 升调射击声 |
| 防风挡板 | 青色矩形护盾扩散 | 高频展开声 |
| 拉升 / 俯冲 | 奶油色尾迹 | 短促引擎滑音 |
| 应急冷却 | 青色冷却液像素上浮 | 柔和高频音 |
| 引擎超频 | 黄色电火花 | 短促升调提示 |
| 敌人命中 / 过热 | 红色屏幕边缘警示 | 低频警报声 |

## UI 可读性底线

- 卡牌费用使用深色底、白色字。
- 卡牌热量固定放置于 28 像素高的类型色底栏。
- 敌人意图使用邮政红底和白色字，永远高于单位名称层级。
- 颜色只用于辅助分类；费用、热量、护盾等信息必须同时显示文字或数字。
