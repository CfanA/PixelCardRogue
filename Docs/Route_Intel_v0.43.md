# 航线情报 v0.43

## 获取与作用

| 前哨航点 | 获得情报 | 首领战首轮效果 |
|---|---|---|
| 雷幕先导追猎 | 雷幕航道密钥 | 雷幕云龙的唯一安全航道固定为玩家当前航道 |
| 双频天穹封锁 | 双频终局解码器 | 根据最终选择自动应用雷幕密钥或磁针罗盘 |
| 磁针鳐卫伏击 | 磁针偏航罗盘 | 磁暴巨鳐的首轮锁定偏转至远端航道 |

情报只改写对应首领的首轮目标，不增加机体属性，也不削弱二阶段矩阵。它的价值来自把前哨学习转化为一次可靠的终局开局计划。

## 信息与持久化

- 路线 HUD、首领战顶部和送达页显示当前情报。
- 单局存档 `RunSaveData.RouteIntel` 保存枚举值，版本提升到 v5。
- v1—v4 存档迁移为“无情报”；非法值恢复为“无情报”。
- 战斗入口存档恢复时重新传入情报，因此退出重进不会改变首轮锁定。

## 验收边界

- 雷幕情报不影响磁暴巨鳐，磁针情报不影响雷幕云龙。
- 双频解码器对两者均生效，但一次运行仍只记录一个情报状态。
- 所有效果均可从战斗开始时直接观察，不依赖隐藏概率。
