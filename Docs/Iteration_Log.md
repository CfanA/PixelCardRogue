## v0.4 — 轮廓、意图与数据迭代

- 玩家邮运机增加邮政白条与红色邮件标记。

- 最终结算新增总回合、出牌数、累计受伤与过热次数。
- 精英总耐久由61降低到52，高伤害单位从8点调整为7点。
- Boss耐久由58降低到50，普通攻击由9点调整为8点，全航道磁暴由6点调整为5点。

## v0.5 — 平衡验证与求职交付

- 建立三种固定构筑路线的自动策略测试：基础牌组、稳健构筑与高热构筑。
- 记录每场战斗的胜负、剩余耐久、货物完整度、回合、出牌、受伤与过热数据。
- 三条路线中两条成功通关；基础牌组止步 Boss，验证了构筑与商店维修的实际价值。
- 稳健构筑以21点耐久、2点货物完整度通关；高热构筑以6点耐久、0点货物完整度险胜。
- 自动测试未出现过热，说明当前策略会主动规避风险；真人测试仍需验证玩家是否愿意主动使用高热牌。
- 完成游戏策划作品案例、平衡测试报告和真人试玩反馈表。
- 将可执行试玩版与设计文档整理为独立求职交付包。

## v0.6 — 霓虹街机 UI 与战斗动效

- 顶部资源区改为模块化 HUD，能量与护盾使用发光刻度显示，货物状态增加独立警示边框。
- 手牌增加像素描边、可用卡呼吸高亮、悬停抬升与不可用遮罩，强化操作状态区分。
- 射击和齐射增加光迹、蓄能光晕、命中爆星；护盾增加扩散光幕；受击增加红闪与像素爆裂。
- 加入不同强度的程序化震屏，使普通射击、过载攻击、齐射和敌方命中具有不同重量。
- 新增任务开始、首领警告、超频、受击与完美规避的横幅提示。
- 所有效果均为程序化原创表现，不使用参考作品的角色、图标或界面素材。

## v0.8 — 街机卷轴背景与重型打击反馈

- 根据实机反馈弃用静态像素云海插画，改为完全程序化的横向卷轴背景。

- 普通射击、过载攻击和全航道齐射使用不同光束粗细、震屏强度与命中停顿时长。
- 敌机命中后增加后坐位移和高频抖动，强化受力感。
- 新增低频噪声爆破音，与高频射击音叠加形成更厚重的听觉反馈。
- 静态背景素材移出运行时资源，保留为被淘汰方案，体现反馈驱动的迭代过程。

## v0.13 — 多货物合同系统

- 新增独立的开局合同选择界面，将“货物即规则”从单一约束扩展为三种构筑方向。
- 易碎药剂：单次受到6点以上未抵消伤害时损失完整度，基础报酬，强调护盾与规避。
- 零度血清：回合结束时热量达到6点时损失完整度，报酬增加15%，强调冷却和爆发节奏。
- 风暴核心：连续两回合没有切换航道时损失稳定度，报酬增加25%，强调机动与卡序规划。
- 当前合同会同步到路线页、运行 HUD、战斗顶栏、奖励牌、商店货架与最终结算。
- 三种合同提供不同的第一轮奖励与商店卡牌倾向，使规则约束能够真实改变构筑路径。
- 货物损坏时触发全屏 `CARGO BREACH` 警报、原因提示、震屏和双层警报音，不再只改变顶栏数字。
- 自动规则校验覆盖零度血清高热损坏和风暴核心两回合失稳；风暴核心已在 Unity 中实机触发，正式构建成功，0 警告、0 报错。

- 建立六套拥有独立资源循环的构筑：锁定狙击、矢量追猎、护盾冲角、零度循环、熔炉爆发和蜂群弹幕。
- 三份合同分别引导两套构筑，并同步调整普通奖励池、商店货架与协同标签；基础卡也能接入动量、护盾和低温循环。
- 战斗 HUD 新增锁定与动量计数，相关卡牌拥有对应命中、换道、冷却、护盾和全屏弹幕反馈。
- 新增长文本自适应标签：在卡牌、奖励、商店、合同、航线和事件容器内自动换行并逐级缩小字号。
- 航线与事件页不再显示会跟随鼠标遮挡正文的操作提示；分支描述获得更高的安全文本区。
- 构建前自动验证六套循环的层数消耗、能量返还、护盾转伤、低热增伤、储热清场和多段伤害结果。
