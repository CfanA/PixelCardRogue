# 《云海邮差》v0.28 设置与输入规范

## 设置数据

设置以版本化 JSON 保存到 Unity `PlayerPrefs` 的 `SkyCourier.Settings.v1` 键中。旧版音乐和音效音量会在首次加载时迁移。

设置与单局存档分离。Steam Cloud 后续只同步玩家档案和单局数据，不同步显示器相关设置，避免玩家更换设备后得到不可用的分辨率或显示模式。

## 显示设置

- 模式：窗口、无边框全屏、独占全屏。
- 分辨率：1280×720、1600×900、1920×1080、2560×1440、3840×2160。
- 垂直同步：开启或关闭。
- 帧率上限：30、60、120、144、240 FPS；开启垂直同步时由显示器刷新率控制。

游戏继续使用1600×900参考画布并保持16:9内容比例，额外空间使用居中安全区。后续分辨率测试必须覆盖720p、1080p和1440p窗口/全屏组合。

## 音频与动态效果

- 音乐音量：0—100%。
- 音效音量：0—100%。
- 震屏强度：0—100%。
- 闪光强度：0—100%。

闪光强度作用于攻击全屏冲击、命中白闪和危险边框；设为0时跳过相关全屏闪光。震屏设为0时不改变逻辑事件，只移除画面位移。

## 手柄映射

| 操作 | 手柄 |
|---|---|
| 移动焦点 / 调整选项 | 左摇杆 |
| 确认 / 打出卡牌 | A |
| 返回 / 打开暂停 | B |
| 结束回合 | Y |
| 暂停 / 继续 | Menu |

所有关键流程必须能够在不使用鼠标和键盘的情况下完成：

- 标题页继续、新配送和设置。
- 四份合同选择。
- 路线分支选择与进入节点。
- 手牌选择、出牌和结束回合。
- 奖励选择与跳过。
- 商店购买、维修和离开。
- 事件、维修坞和最终结算。
- 教学、暂停和设置。

手柄最近一次产生输入后显示金色脉冲焦点和底部按键说明；鼠标移动、点击或滚动后隐藏手柄焦点。
