# 《云海邮差》Steam 产品化规格 v0.27

## 产品目标

将当前战斗与航线原型发展为可在 Steam 正式销售、支持持续游玩和稳定更新的单机卡牌构筑肉鸽。

正式版首先保证以下体验：

- 玩家可以随时安全退出，并从清晰的检查点继续。
- 失败原因可读，下一局存在明确的新尝试目标。
- 键鼠、主流手柄和 Steam Deck 均可完成全部操作。
- 存档、设置和版本升级不会破坏玩家进度。
- 商店页展示的玩法、画面和实际产品一致。

## 当前产品边界

### 已验证

- 三航道战斗、能量、热量、护盾和敌方意图。
- 四份规则型合同。
- 卡牌构筑、A/B 强化分支和稀有模块。
- 八阶段、十九节点的分支航线。
- 普通、精英、追猎、事件、商店、维修和两阶段首领。
- Windows 64 位构建。

### 尚未达到正式发行标准

- 永久档案与局外解锁。
- 完整手柄导航和键位重绑定。
- 分辨率、显示模式、可访问性和特效强度设置。
- Steam Cloud、成就、统计和 Steam Deck 验证。
- 版本化内容数据、迁移测试、崩溃诊断和自动化回归。
- 足够支撑正式售价的区域、遭遇和长期发现内容。

## v0.27 第一里程碑：可靠单局恢复

### 存档文件

存档位于 Unity 的 `Application.persistentDataPath`：

- `run.json`：当前有效单局。
- `run_backup.json`：写入新存档前保留的上一份有效单局。
- `run.tmp`：原子替换过程中使用的临时文件。

存档包含版本号、UTC 保存时间、牌组、强化分支、模块、合同、机体、货物、邮票、航线进度、节点状态和累计战斗统计。

### 自动保存点

- 选择合同并创建新单局。
- 选择航线节点。
- 进入战斗、商店、事件或维修坞。
- 商店购买或维修完成。
- 事件或维修选择生效。
- 战斗胜利进入奖励页。
- 奖励领取或跳过并返回地图。

### 恢复语义

- 地图、商店、事件、维修和奖励页恢复到最近一次保存后的状态。
- 战斗内退出后，从该场战斗入口重新开始。
- 配送完成后删除当前单局存档。
- 主存档不可读取时尝试恢复备份；不自动删除损坏文件。

战斗入口恢复是 v0.27 的明确设计选择：当前版本不序列化抽牌堆顺序、敌方行动阶段和表现动画，避免生成表面可读取但无法可靠恢复的战斗中间状态。

## 后续里程碑

### v0.28：设置与输入

- 全屏、无边框、窗口和分辨率设置。
- UI 缩放、帧率限制和垂直同步。
- 震屏、闪光和故障效果强度。
- 完整手柄导航、焦点反馈和键位重绑定。
- 输入设备变化时自动切换按键提示。

### v0.29：可诊断与数据化

- 每局可复制随机种子。
- 版本、路线、构筑和死亡原因日志。
- 卡牌、遭遇、事件和合同从表现类中分离。
- 关键规则的编辑器回归测试。
- 存档升级和损坏恢复测试。

### v0.30：局外留存

- 飞行员或机体的横向差异。
- 新合同、卡牌包、模块和区域的逐步解锁。
- 邮政档案、敌机图鉴和配送记录。
- 难度等级与长期挑战。
- 解锁以新玩法为主，避免单纯永久数值碾压。

### Steam Demo 里程碑

- 一局 25—35 分钟。
- 一个完整区域和正式首领。
- 至少三条可识别构筑路线。
- 完整存档、设置、手柄和 Steam Deck 操作。
- Demo 结束页展示正式版内容并提供愿望单入口。
- 至少完成两轮外部玩家测试后再公开。

## 质量门槛

任何公开版本都必须满足：

- 干净环境可完成 Windows 正式构建。
- 核心规则校验无异常。
- 新玩家不依赖开发者解释即可完成首局。
- 任何正常退出点都不会丢失超过一个明确检查点的进度。
- 关键文本在目标分辨率下无裁切。
- 没有阻断流程、损坏存档或无法继续的已知问题。
