# 云海邮差 v0.60 验收说明

## 本版目标

v0.60 对主要玩家界面进行系统可读性优化。玩法规则和战斗数值不变；重点统一字号下限、信息层级、对比度与密集文本布局。

## 可读性验收

1. 进入任意战斗。顶部合同被动、空域规则或 Boss 矩阵、托管状态均应保持清晰，不再缩成极小文字。
2. 敌人意图应继续使用“符号 + 标题 + 解释”双层信息卡；敌机名称、生命与装甲文字应清楚可辨。
3. Boss 第二阶段反制协议应使用加高的信息条，协议内容不应缩成一行难辨小字。
4. 无法使用的手牌应覆盖较深遮罩，并在独立高对比面板中显示禁用原因；禁用原因不得与原规则正文叠读。
5. 打开 12 区航图。节点状态应随语言显示为“完成 / 当前 / 可进入 / 已错过 / 待解析”，节点名称、高度标签、详情与拖动提示应清晰可读。
6. 打开系统设置与 F1 规则书。设置标签、当前值、百分比、词典目录和操作提示应维持稳定字号。
7. 在简体中文与 English 间切换。地图节点类型与状态不应混入另一语言，长文本不应越出面板或遮挡相邻控件。

## 回归验收

- 12 区航图仍可按住拖动、滚轮浏览、按钮翻页和滚动条定位。
- 当前区域后两列以外仍只显示通用问号信标和“航路情报未解析”，不得泄露节点类型与连线。
- 长按敌人查看敌情详解、首次教学、F1 词典和设置开关保持可用。
- 卡牌可用性、出牌结果、敌方意图与 Boss 规则没有数值或机制变化。

## 自动验证范围

- 发布规则固定辅助文本不低于 10px、正文不低于 12px、关键决策文字不低于 14px（1600×900 参考画布）。
- 验证 4:3、16:9、16:10 与 21:9 共 10 档视口矩阵。
- 运行卡池、敌人、路线、工坊分支、存档、本地化与全部核心规则验证。
- 编译 Windows x64 Player，并复制本验收说明与教学重置启动器。
