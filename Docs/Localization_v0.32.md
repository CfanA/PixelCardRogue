# 《云海邮差》v0.32 本地化基础

## 目标

v0.32 建立可持续扩展、可自动校验的双语管线，为 Steam 商店页与英文试玩版本做准备。本轮不修改任何卡牌、敌人、合同、奖励或经济数值。

## 已完成

- 新增 `Resources/Localization/localization.txt`，以 TSV 三列格式和稳定文本键统一维护简体中文与 English。
- 新增运行时本地化服务，支持参数化文本、换行转义、缺失键中文回退与语言即时切换。
- 设置数据升级到 v2，保存语言选择，并自动兼容 v1 设置及更早的独立音量偏好。
- 设置页新增语言选项；键鼠、键盘和手柄均可切换，修改后立即保存。
- 首批覆盖标题、设置、暂停、邮政档案、失败复盘，以及合同、卡牌、模块和档案敌机名称。
- 构建前自动扫描代码中已接入的静态文本键，并额外检查全部动态卡牌名称是否同时具有中英文。
- 构建前验证中文/英文查找、参数替换、卡牌名称切换及设置 v1 → v2 迁移。

## 当前覆盖边界

这不是“完整英文版”的声明。战斗规则长文本、敌机变体名称与意图、航线节点、事件、商店、奖励、教学和结算页仍以中文为主。当前版本的价值在于先固定语言选择、资源格式、稳定键名与验证方式，再按玩家实际游玩顺序迁移剩余内容。

## 下一阶段建议

1. 优先迁移新手首次 20 分钟：合同选择、地图、首战教学、卡牌规则、敌机意图和战斗 HUD。
2. 再覆盖完整航线：奖励、商店、事件、维修、Boss、胜利结算与错误提示。
3. 加入英文字体和字符缺失审计，按 16:9、16:10、超宽屏与 Steam Deck 分辨率进行截断检查。
4. 完成术语表和译文语气规范，再进入 Steam 商店页、成就、云存档与平台 API 文案。
