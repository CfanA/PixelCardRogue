# 云海邮差 v0.58 验收说明

## 本版目标

v0.58 新增“长按敌人查看敌情详解”，解决敌方意图字小且复杂机能无法在战斗中快速查阅的问题。此版本不调整敌人数值平衡。

## 功能验收

1. 开始一场战斗。在首次意图教学关闭后，应自动出现“敌情详解”教学；已经看过旧教学的存档也会单独收到一次新教学。
2. 在存活敌人的机体上持续按住鼠标左键约 0.45 秒。按住期间应显示解析进度，完成后打开敌情详解。
3. 详解面板应显示敌人名称与分类、当前生命和装甲、航道与阶段、本回合意图、固有机能、实时状态和应对建议。
4. 保持按住时面板持续显示；松开鼠标后立即关闭，且不应误触发出牌或结束回合。
5. 多种普通、精英、中阶 Boss 与终局 Boss 均应显示各自的机能和反制建议，不应统一显示为 Boss 规则。
6. 按 F1 打开规则词典，左侧应有 11 个条目，其中“敌情详解”可随时重看，且列表不遮挡底部返回按钮。
7. 打开系统设置，“长按敌情详解”开关默认开启。关闭后长按敌人不再触发；重新开启后恢复，并在重启游戏后保留设置。
8. 切换 English 后，教学、设置与敌情面板均应显示英文，不能出现缺失键或中文回退。

## 首次教学复验

构建目录内提供 `Reset Tutorials and Play.bat`。运行它会清除教学进度并启动游戏，便于重复验收首次教学，不会清除正常配送存档。

## 自动验证范围

- 运行全部核心规则、卡池、敌人、路线、存档和本地化验证。
- 验证设置 v4 JSON 往返，确认敌情开关可持久化。
- 验证 11 项教学词典覆盖与中英文敌情教学键。
- 编译 Windows x64 Player，并随构建复制本验收说明与教学重置启动器。

## 非本版范围

敌人生命、伤害、打断阈值与奖励数值继续保持现阶段设计，等待后续真人试玩数据后统一平衡。
