# 《云海邮差》核心设计文档（更新至 v0.60）

## 一句话概念

玩家驾驶可改装的老式邮运机，在三条空中航道中使用指令卡战斗，并带着会改变战斗规则的特殊货物穿越云海。

## 项目定位

- 类型：单机、回合制卡牌构筑、轻度肉鸽
- 平台：Windows x64
- 单局目标时长：20—30 分钟
- 目标体验：短促爽快的像素空战演出 + 可预判的空间决策 + 由配送合同制造的风险收益
- 作品集展示重点：核心循环、系统联动、数值迭代、关卡与事件设计、可用性验证

## 当前试玩结构

- 单局分为 5 层、12 个航区和 33 个节点；第 3 层进行中阶 Boss 体检，第 5 层收敛至四类终局 Boss。
- 路线同时承载普通战、精英战、追猎、事件、补给站、维修坞和风险收益分支，并仅解析当前区域后两列情报。
- 卡牌目录包含 123 种卡牌、五份合同池、15 张跨体系牌与六类持续航道协议；全部卡牌支持工坊 A/B 分支改写。
- 战斗使用三航道、意图预告、热量、护盾、合同风险和货物完整度形成共同决策；长按敌人可查看完整机能与实时状态。
- 局外档案记录挑战、合同精通、构筑快照、四类 Boss 和十二种结局，不提供永久战斗数值加成。
- 本文后续的“v0.2 单局航线结构”和初始卡表保留为历史原型基线；当前版本变化以根目录 `CHANGELOG.md` 与验收文档为准。

## 核心卖点

### 1. 三航道空战

玩家与敌人分布在上、中、下三条航道。多数直射武器只能攻击同航道目标；机动牌用于改变位置、躲避预告攻击或寻找射界。移动不是动画表现，而是战斗资源。

### 2. 能量与过热的双资源

能量限制每回合出牌数量；强力武器会积累热量。热量达到上限会导致机体受损，因此玩家需要在立即爆发、主动冷却和承受风险之间选择。

### 3. 货物即规则

货物会占据有限货舱，并为战斗增加特殊约束。完成约束可获得额外报酬，失败则降低收益或改变后续事件。

首个验证货物“易碎药剂”：若玩家单次受到 6 点或以上伤害，货物损坏一层。它鼓励玩家阅读敌人意图、使用护盾与机动牌，而不是单纯抢伤害。

## 首版战斗循环

1. 回合开始：能量恢复，抽至 5 张牌，敌人展示意图。
2. 玩家阶段：打出武器、机动、防御与冷却牌。
3. 回合结束：敌人依次执行预告行动。
4. 热量自然下降，进入下一回合。
5. 消灭所有敌人获得胜利；机体耐久归零则配送失败。

## v0.2 单局航线结构（历史原型基线）

1. 废弃风标：普通战，用于建立本局战损与第一笔经济收入。
2. 战后奖励：三选一卡牌，也可跳过并获得15枚邮票。
3. 浮岛补给站：购买卡牌或修复机体，形成构筑与生存之间的经济取舍。
4. 雷暴封锁线：精英战，使用更高伤害和全航道攻击检验构筑。
5. 第二次战后奖励：提供高热量、高收益卡牌。
6. 磁暴鳐巢：Boss战，每三回合发动一次5点伤害的全航道磁暴攻击。

机体耐久、货物完整度、邮票和牌组会跨节点保留，构成一局约10—15分钟的短流程。

## 首版验证指标

- 玩家能否在第一场战斗内理解“同航道射击”。
- 敌人意图是否足以支持玩家提前规划移动。
- 过热是否造成真实取舍，而不是无脑避免。
- 易碎货物是否改变防御牌的价值判断。
- 单场战斗是否能控制在 4—7 回合。

## 明确不做

首个原型暂不制作局外成长、完整剧情、大量卡牌、角色养成与商业化系统。先验证战斗决策，再扩展肉鸽地图。
