# 《云海邮差》v0.33 机库合同轮盘

## 设计目标

旧合同页一次展示四张同权重信息卡，虽然信息完整，但更像配置表而不是一次有分量的局前选择。v0.33 将合同视为本局的“角色身份”，参考角色选择界面的聚焦方式，在不引入 3D 模型和额外渲染管线的前提下建立伪 3D 机库。

## 视觉结构

- 当前合同位于中央前景，拥有最大尺寸、完整亮度、投影和霓虹框。
- 相邻合同缩小、下沉并移向两侧，远端合同进一步暗化，形成景深与透视感。
- 机库使用逐层收缩框架、地面扫描线和中央照明带模拟纵深。
- 合同切换采用平滑阻尼，不会瞬间跳位；轮盘首尾连续循环。
- 中央信息只保留风险条件、构筑路线、玩法说明和报酬，降低四卡同时阅读造成的认知负担。
- 点击侧面合同会将其切换到中央；界面不再显示独立的左右切换按钮，中央“签署合同”按钮负责最终确认。
- 合同页暂停按钮移入右上角面板安全区，不再跨越霓虹外框。

## 输入

- 鼠标：点击两侧合同切换；滚轮可连续浏览；中央按钮确认。
- 键盘：方向键或 A/D 切换，1—4 快速定位，Enter 签署。
- 手柄：左右方向切换，A 签署。

## 设置按钮修复

原步进按钮复用会自动绘制 `〈 label 〉` 的通用大按钮，导致 `<` / `>` 在窄按钮内变成多层括号并产生视觉错位。现在使用专用步进按钮：

- 不再追加装饰括号。
- 左右按钮以设置值面板中心对称。
- 点击区域、投影和悬停边框保持一致。
- 手柄焦点继续覆盖整行设置，不改变原有导航方式。

## v0.34 延伸

轮盘已经为“合同即局前角色”建立了稳定入口。v0.34 已完成第一层延伸：四份合同获得独立战斗被动。后续内容优先推进合同专属卡池和一次不可逆的中期机体改造。
