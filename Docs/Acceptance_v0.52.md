# 《云海邮差》v0.52 渐进式教学、本地化与可访问性验收

> 验收日期：2026-07-27  
> 版本：0.52.0  
> 范围：v0.51渐进教学、v0.52中英文统一、显示与输入辅助  
> 数值基线：沿用v0.50，不调整卡牌、敌人、经济或路线数值

## 验收目标

首局玩家只在相关规则真实出现时收到一次简短演示；之后可随时从规则书复查。中文与英文玩家都能读懂卡牌、意图和战斗反馈，并可用鼠标、键盘或手柄完成主要流程。重要危险同时使用颜色、形状与文字表达。

## 渐进式教学

| 主题 | 行为触发 | 持久化 |
|---|---|---|
| 意图 | 首次进入普通战斗 | 关闭后标记已读 |
| 同航道攻击 | 首次实际命中同航道目标 | 关闭后标记已读 |
| 热量 | 首次打出增加热量的牌 | 关闭后标记已读 |
| 货物 | 合同风险首次降低完整度 | 关闭后标记已读 |
| 换道 | 机动牌首次改变航道 | 关闭后标记已读 |
| 追踪 | 连续换道形成航迹暴露 | 关闭后标记已读 |
| 改装 | 首次进入不可逆机体改装 | 关闭后标记已读 |
| 纪事 | 首次进入三分支信标事件 | 关闭后标记已读 |
| 前哨 | 首次进入补给站 | 关闭后标记已读 |
| Boss | 首次进入终局首领战 | 关闭后标记已读 |

- 自动教学开启时每主题只出现一次；手动规则书浏览不修改教学进度。
- `F1`、暂停菜单“规则说明”和手柄入口可随时打开10主题规则书与统一术语词典。
- 旧首战说明已完成的玩家迁移基础五项，不重复打断；新增路线主题仍可按行为触发。
- 未结算过任何一局的档案直接进入标准派遣，挑战任务在第一次胜负结算后开放。

## 本地化

- 中文/英文设置即时切换并写入本地设置存档。
- 构建前扫描源代码静态键、108张卡牌的名称与规则、10主题标题/触发/正文/词典，以及全部敌方意图。
- 敌机名称、战斗HUD、意图、底部日志摘要和高频战斗横幅不在英文模式显示内部中文状态。
- 英文与中文意图使用同一战斗状态；显示语言不参与伤害或移动判定。
- 字体继续使用项目既有动态字体回退；长标题和意图使用自适应字号，规则正文使用固定宽度换行区域。

## 可访问性与输入

| 项目 | 验收标准 |
|---|---|
| 显示 | 窗口、无边框、独占全屏；多档分辨率、VSync与帧率上限 |
| 视觉强度 | 震屏0/25/50/75/100%，闪光0/25/50/75/100% |
| 音量 | 音乐与音效独立0—100% |
| 教学 | 情境教学可关闭；完整规则书仍可查看 |
| 焦点 | 焦点高亮可关闭；设置界面始终保留焦点，防止键盘/手柄失去位置 |
| 键鼠 | 鼠标按钮、数字键/方向键、Enter、Esc、F1覆盖主要流程 |
| 键盘 | 规则书可用方向键/WASD浏览，Enter/Space关闭 |
| 手柄 | 左摇杆/D-pad选择，A确认，B返回，Y结束回合，Menu暂停 |

## 非颜色表达

- 当前航道：青色底和粗线，同时显示`[>] 航道 n // 当前`。
- 追踪意图：粉色边框，同时显示`X`和“追踪/TRACKING”。
- 雷幕安全/危险：同时显示`[O]`安全文字和`[X]`危险文字。
- Boss反制：颜色面板同时显示双`!!`形状、规则名称和触发状态。
- 热量：橙色进度条同时显示`#`和`热量/HEAT x/y`。
