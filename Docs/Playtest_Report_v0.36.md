# 《云海邮差》v0.36 一页式试玩与平衡报告

> 生成日期：2026-07-26　|　自动构筑模拟：13/16 通关

## 真人试玩结论与本轮目标

v0.36 在航线中段加入一局一次、不可撤销的机体改装分叉；本轮自动构筑继续作为无改装基线，只验证三种规则和原有路线回归，具体数值留待后续专项平衡。

## 已实施改动

- 新增版本化单局存档、上一代备份和损坏回退；地图、战斗入口、商店、事件、维修和奖励节点自动保存。
- 新增窗口/无边框/独占全屏、五档分辨率、垂直同步、帧率上限，以及音乐、音效、震屏和闪光强度设置。
- 标题至结算的全部关键流程支持手柄导航，并持续显示当前焦点和控制器按键提示。
- 每局生成可见种子；同一航点的编队、洗牌和战斗随机行为可稳定复现，恢复战斗不会改变开局状态。
- 本地 JSONL 诊断记录版本、种子、界面、航点、合同、战损和关键流程；Unity 错误另存最后错误上下文，所有记录均不上传。
- 标题页新增邮政档案，长期记录出发、送达、失事、战斗胜利、最佳货物、累计回合和累计出牌。
- 新增合同、卡牌、模块和敌机发现图鉴，以及不提供属性加成的邮差等级与五枚荣誉签章。
- 最近八次送达或失事记录保留合同、航点、种子、回合、牌组等摘要；档案使用独立主文件、备份和安全替换。
- 规则层区分同航道攻击、航道封锁、全航道风暴、航迹追踪、灾变蓄力、首领正面/溅射和引擎过热八类致命来源。
- 失败页显示致命敌机、最后机体损失、对应战术建议、本次档案增量与种子，并提供同合同新种子快速再试。
- 邮政档案 v2 为失败记录保存致命来源；v1 档案自动迁移并保留既有统计和历史记录。
- 新增统一 TSV 双语词表与运行时本地化服务，设置中可即时切换简体中文 / English，语言选择独立持久化。
- 首批英文覆盖标题、设置、暂停、邮政档案、失败复盘，以及合同、卡牌、模块和敌机等核心名称。
- 构建前扫描已接入的静态文本键并验证双语字段，同时验证全部动态卡牌名称、设置迁移和中英切换。
- 四份合同不再同时平铺，改为中央聚焦、两侧后退、远端暗化的伪 3D 机库轮盘，突出本局构筑身份。
- 当前合同集中显示风险条件、推荐构筑路线、玩法说明和报酬；支持鼠标、滚轮、方向键、数字键与手柄切换。
- 设置页步进箭头脱离通用装饰按钮，使用对称专用按钮和独立点击区域，消除窄宽度下的括号拥挤与错位。
- 连续换道累积航迹暴露；第二个连续机动回合会预告并触发一次5点追踪射击。停留会降低暴露。
- 新增信号扰频、逆向追猎、矢量刹车、航道雷网4张牌，以及围绕航迹管理的幽灵黑匣合同。
- 合同各自携带一张开局核心牌；长航线加入追迹者空域，并保留多次补给与维修选择。
- 新增首次战斗提示、暂停、重新开始以及独立音乐/音效音量设置。
- 12种攻击牌获得独立弹道、命中节奏、震屏强度与分层音效；点射、轨炮、制导、冲角、冰枪、热浪、飞弹和雷网可直接从动作轮廓区分。
- 航线扩展为8个阶段、19个节点，包含普通战、精英、追猎、商店、事件、维修坞与首领，并按连线形成多条可选路径。
- 地图支持滚轮、方向按钮和滚动条浏览；只解析当前节点之后两层，未到达情报由信号遮罩隐藏。
- 自动模拟改为4战安全路线与7战高压路线两类配置，覆盖分支带来的成长和战损差异。
