# 《云海邮差》v0.47.1 进入 v0.48 前验收

> 验收日期：2026-07-26  
> 版本：0.47.1  
> 范围：108种卡池、重复入牌、固定开局牌组、删牌与核心校准  
> 结论：通过，可以进入 v0.48  
> 数值状态：未进入系统性平衡

## 验收目标

在不重做 v0.41 数值基线的前提下，把卡牌内容广度补足到至少108种，并建立能真正承载大卡池的单局获取、重复购买、删牌、开局牌组与起手保护流程。

本验收中的“108张”指108种独立卡牌。玩家单局牌组中的实际卡牌张数不受此数字限制，同种卡牌允许存在多个副本。

起手置换只降低“牌组明明有攻击牌却开局完全摸不到”的非决策性风险，不限制玩家主动构筑。玩家删光直接伤害牌后，系统接受这个选择。

| 验收项 | 结果 |

| 奖励角色覆盖 | 每组至少含1张直接伤害牌与1张支援牌 |
| 合同签名保障 | 尚未取得时放在首次普通奖励第一项 |
| 商店卡牌 | 按种子、航点和空域生成3张，可购买已有卡牌的重复副本 |
| 全池可达 | 五合同、三空域、每组4096个种子验证全部通过 |
| 删牌入口 | 维修坞可删除任意1张现存副本 |
| 删牌硬下限 | 无；不限制牌组张数，也不限制直接伤害牌数量 |
| 强化清理 | 删除最后一张副本时移除该牌的本局强化与分支记录 |
| 合同核心校准 | 维修坞可为合同开局核心选择或重选A/B分支 |

奖励和商店使用确定性种子。同一输入得到同一组三选一，已有卡牌仅承受轻度发现权重修正，不会被排除，因此重复构筑不会在获得一张后失去后续来源。

## 新增机制与效果

- 68张新增牌全部拥有独立卡牌定义、费用、热量、家族、规则与实际战斗结算。
- 新增消耗区；紧急分拣与死信投递打出后不会进入普通弃牌堆。
- 新增整手循环、回合结束保留手牌、从抽牌堆检索武器牌。
- 新增护盾、热量、锁定、动量、暴露与剩余能量之间的双向转换。
- 新增同航道、任意敌人和其他航道目标门槛，不能命中合法目标时不会错误打出。
- 新攻击牌接入单发、齐射、机动、冷却、护盾和超频反馈分类。

## 兼容与持久化

- 旧40张卡牌枚举值不变，既有单局存档中的牌组整数仍指向原卡牌。
- 新牌只追加编号，没有重新排序旧牌。
- 单局存档继续保存实际牌组副本，因此奖励、购买和删牌结果自动持久化。
- 空牌组也可正常保存与读取，删牌不会被存档层隐式加回下限。
- 新开局配方只影响新配送；读取旧单局时保留旧档中已经存在的牌组。
- 新维修子界面沿用现有字符串界面状态保存，不需要提升单局存档版本。
- 删除最后一张副本会清理本局强化映射，避免未来保存无主强化记录。
