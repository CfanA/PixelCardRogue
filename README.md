# 云海邮差（Sky Courier）

**像素风空战牌组构筑 Roguelite · Windows 试玩 v0.60**

驾驶一架邮运机穿过云海。每次出发前，你要接下一份配送合同，再用卡牌换道、开火、冷却，把货物带过沿途的空战和雷暴。最难的决定常常发生在回合结束前。多开一炮可能击落敌人，也可能让机体过热，或者让易碎货物暴露在下一次攻击里。

## 一趟配送怎么玩

**接合同 → 签离港条款 → 选航点与战斗 → 补给、改牌和改装 → 终局交战与配送结算**

出发时，合同决定货物风险和专属被动。路上可以用邮票修机体、补牌或改写一张牌的分支。机体、货物和牌组会随航线继续带到下一站，因此眼前的打法也会影响下一场战斗。

## 玩法设计

### 换一条航道，就换了一组能打的目标

上、中、下三条航道同时决定射界与来袭方向。多数直射武器只能打到同航道的敌人。看到攻击预告后，可以花能量换道，再寻找射击机会，也可以留在原位用护盾挡住攻击。连续换道可能招来追踪火力，爆发出牌又会积攒热量。一个回合里，玩家要同时决定站哪儿、打谁，以及留多少余地应对接下来的攻击。

### 货物让同一手牌有不同的价值

接下**易碎药剂**时，单次未被护盾抵消的伤害达到 6 点就会损伤货物。用护盾完全挡下一击还可以获得锁定，为下一次射击创造机会。改接**零度血清**，重点变成在结束回合前控制热量，主动降温还能换回能量。换合同会改变出牌顺序，也会改变后续想拿哪些奖励牌。

### 航线和工坊一起决定牌组怎么长

航图只揭示接下来两列的具体信息。玩家可以走危险航道争取更适合构筑的奖励，也可以先绕到补给站修机体、删牌或改写卡牌。工坊的 A/B 选项会改变同一张牌的效果，例如改变它提供的防护或触发条件。临近终局的前哨战会先预演部分首领规则，并给出能影响首领开局的情报。

### 让失败留下下一局可以尝试的办法

失事结算会拆出致命伤害、护盾吸收与牌组短板，并给出一条可以执行的调整方向。玩家可以保留合同和种子复飞，试着调整换道时机、加一张防御牌或换一条航线，再看同一开局能走多远。

## 开发阶段

| 阶段 | 做了什么 |
| --- | --- |
| 01 · 战斗原型（v0.2） | 把三航道、同航道射击、敌人意图和过热放进一条短航线，先验证换道和冷却能否改变每回合的决策。 |
| 02 · 合同与构筑（v0.34–v0.47.1） | 给合同配上专属被动、风险和卡牌，让保护货物的方式逐渐变成可持续的构筑方向。加入前哨情报、固定种子挑战和邮差档案。 |
| 03 · 单局结构与复盘（v0.48–v0.53） | 用离港条款、机体改装和终局准备划分单局阶段，记录沿途构筑变化。为失事结算加入归因和快速复飞。用固定种子回归覆盖规则，并根据当时能核实的试玩记录小幅调整两张牌。 |
| 04 · 扩展航线与可读性（v0.54–v0.60） | 扩成五层远征与连续航图，把敌人意图拆成预警和解释，为禁用牌单独显示原因。玩家可以在出牌前看清眼前的限制，再决定怎么应对。 |

## 当前试玩范围

v0.60 包含 **5 份合同、123 张卡牌、12 个航区和 33 个航点**。四类终局首领与信标纪事的三种立场组合成十二种可归档的结局。当前阶段重点是打通单局流程，并让战斗预警、地图风险和卡牌限制更容易读懂。
